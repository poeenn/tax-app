# かんたん経費ノート — 配信者向け経費記録アプリ

ストリーマー・VTuber・ライバーが、会計知識なしで日々の経費を簡単に記録できる PWA です。

## 技術スタック（MVP）

| レイヤー | 採用技術 | 理由 |
|---------|---------|------|
| フロントエンド | React 19 + Vite 8 | 高速開発、既存プロジェクトを活用 |
| ルーティング | React Router 7 | 画面遷移・モバイルナビ |
| 状態管理 | React Context | MVP には十分、シンプル |
| 永続化 | localStorage | バックエンド不要で即動作 |
| UI | CSS Variables + Lucide Icons | 初心者向けポップでかわいいデザイン |
| ビルド | Vite PWA | PWA対応済（スマホのホーム画面に追加可能） |

### Phase 2 以降（未実装）

## 機能

- PWA対応（スマホのホーム画面にインストール可能）

- 経費の手入力登録
- レシート・スクショの画像アップロード（Inbox）
- 配信者向け10カテゴリでの分類
- 事業使用割合スライダー（50% / 70% / 100%）
- 年間・月別・カテゴリ別サマリー
- JSONファイルの出力・読み込みによるデータバックアップ/復元
- CSV エクスポート（税理士・会計ソフト連携用）
- localStorage によるデータ永続化

## 起動方法

```bash
cd SP_app/tax-app
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

## 画面構成

| パス | 画面 |
|------|------|
| `/` | ホーム（年間経費サマリー・追加導線） |
| `/inbox` | 未分類リスト・画像アップロード |
| `/add` | 手入力で経費追加 |
| `/categorize` | まとめて分類フロー |
| `/categorize/:id` | 個別アイテムの分類 |
| `/summary` | サマリー・CSV出力 |

## ディレクトリ構成

```
src/
  components/     # UI 部品
  context/        # ExpenseContext（グローバル状態）
  data/           # 配信者向けカテゴリ定義
  pages/          # 画面コンポーネント
  utils/          # 計算・CSV・localStorage
```

## 法務上の注意

本アプリは**経費の記録ツール**です。税務判断・申告書作成・個別の節税助言は行いません（税理士法に配慮）。
